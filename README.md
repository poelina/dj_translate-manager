# Система приёма заказов на переводы (Django)

Веб-приложение на Django для автоматизации приёма заказов в бюро переводов. Проект предлагает клиенту удобный пошаговый интерфейс для оформления заявки, а сотрудникам компании — полноценную панель управления для обработки входящих заказов.

## 🚀 Архитектура и ключевые фичи

*   **Умный диспетчер услуг (Шаг 0):** Главная страница определяет потребность клиента и перенаправляет его на изолированные, специализированные пайплайны (`text`, `speech`).
*   **Динамическая многошаговая форма (Multi-step Form):** Реализована на одной странице без перезагрузок (с помощью JavaScript и CSS-состояний) с визуальным трекером прогресса сверху.
*   **Условный рендеринг полей:** Форма адаптируется на лету — скрывает/показывает поле загрузки файлов в зависимости от способа передачи оригинала, а также динамически разворачивает поля для юридических лиц.
*   **Интерактивный сводный экран:** На финальном шаге клиент видит структурированную сводку всех введённых данных перед отправкой.
*   **Безопасность и защита данных:** Использование CSRF-токенов, валидация дат (запрет выбора прошедших дней) и паттерн *Post/Redirect/Get* для защиты от дублирования заказов при обновлении страницы.

## 📂 Структура базы данных (`models.py`)

Проект использует единую гибкую модель `Order`, которая агрегирует:
1.  **Системные данные:** Тип услуги (`text` / `speech`), дата создания.
2.  **Параметры перевода:** Язык оригинала, язык перевода, дедлайн, количество страниц.
3.  **Логистику:** Метод передачи оригинала (`digital` / `post` / `office`), файловое хранилище (автоматическая сортировка документов по папкам).
4.  **Профиль клиента:** Имя, фамилия, email, телефон, b2b-флаг (компания) и Названия организации.
